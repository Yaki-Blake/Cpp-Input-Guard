# C++ Input Protection（C++ 输入保护）

[English](README.md) ｜ **简体中文**

Obsidian 插件：让 Markdown 语法不再干扰 C++ 笔记。输入时拦截、粘贴时同样处理，也能把已经写好的旧笔记一次性修复——同时放过围栏代码块、行内代码和正常的链接语法。

## 解决的问题

Obsidian 渲染的是 Markdown，而 Markdown 给很多 C++ 天天在用的符号赋予了第二重含义。

| 你写的 | Markdown 看到的 | 后果 |
| --- | --- | --- |
| `greater<int>` | 一个未闭合的 HTML 标签 | 后续同级内容全被吞进该元素：列表圆点变成字面 `*`、段落粘连、缩进错乱。实时预览与阅读视图同时崩 |
| `arr[5]`、`[note]` | 链接 / 引用 / 脚注的起点 | 方括号从输出里消失，或变成一个指向不存在目标的链接 |
| `#include <iostream>` | 标签 | `#include` 被收进标签面板，每篇笔记都再污染一点 |
| `if (a == b) return c == d;` | 高亮定界符 | 同一行两个 `==` 会把中间内容整体渲染成高亮 |
| `a*b*c`、`int** p` | 强调语法 | 两侧不贴空白的两个星号会变成斜体 / 粗体 |
| `"C:\\path"`、`"100%%"` | 转义序列 | 反斜杠悄悄吞掉后一个字符，渲染结果里它就没了 |

尖括号这一类，Obsidian 官方文档给了三种解法：手动闭合标签、用反引号包住、或者**用反斜杠转义**（`\<`）。本插件把第三种自动化，覆盖 `<`、`[`、`*`、`_`、`=`、`#`，既管新输入，也管存量笔记。

## 功能

| 功能 | 说明 |
| --- | --- |
| 输入拦截 | 在捕获阶段接住 `<`、`[`、`*`、`_`、`\`、`=`，Obsidian 的自动配对根本看不到这次按键 |
| 粘贴拦截 | 粘进正文的文字走同一套规则；粘进代码块的不动 |
| 输入即转义 | 写入 `\<`、`\[`、`\*`、`\_`、`\\`，渲染结果仍是字面字符 |
| 代码感知 | 围栏代码块（``` / ~~~）与行内代码一律不碰，`#include <iostream>`、`arr[0]` 保持原样 |
| 尖括号智能判断 | `a < b`、`x <= y`、`<3` 一律放行，只转义真会变成标签的写法 |
| 方括号智能判断 | 保留 `[文字](地址)`、`[[双链]]`、`[文字][引用]`、`[^脚注]`；转义 `arr[5]`、`a[i][j]`、裸 `[note]` 这类下标与孤立方括号 |
| Markdown 语法抑制 | `==` 不再触发高亮（只有 `===` 触发）；`*` 与 `_` 不再触发行内强调；`\` 按字面显示；C/C++ 预处理指令不再被当标签 |
| 存量笔记修复 | 五条命令：当前笔记 / 当前文件（阅读视图可用）/ 整个库 / 选区 / 打开时自动 |
| 自动备份 | 每次修复写盘前，先在文件旁边留一份 `<原名>.md.bak-<时间戳>`（默认开启） |
| 从备份还原 | 设置面板里选笔记、选版本还原；也可以用命令把当前文件回滚到最近一份备份 |

## 安装

### 手动安装

1. 从[最新 release](../../releases/latest) 下载 `main.js`、`manifest.json`、`versions.json`。
2. 新建文件夹 `<你的库>/.obsidian/plugins/cpp-input-protection/`，把三个文件放进去：

   ```
   <你的库>/.obsidian/plugins/cpp-input-protection/
   ├── main.js
   ├── manifest.json
   └── versions.json
   ```

3. 打开 **设置 → 第三方插件**，点 **刷新**，再启用 **C++ Input Protection**。如果列表里看不到它，确认「受限模式」已关闭。

### 用 BRAT 安装

在 BRAT 提示时填 `Yaki-Blake/Cpp-Input-Protection`，之后它会从本仓库的 release 自动安装与更新。

要求 Obsidian 1.4.0 或更高。纯 JavaScript，`main.js` 就是最终产物，不需要构建、没有第三方依赖。桌面端与移动端都可用。

## 使用

### 打字

不需要配置。启用插件后：

| 你按下的键 | 编辑器写入 | 作用 |
| --- | --- | --- |
| `<` | `\<` | 阻止自动配对与 HTML 解析 |
| `[` | `\[` | 阻止自动配对与链接解析 |
| `*` | `\*` | 阻止斜体 / 粗体 |
| `_` | `\_`（仅在词边界，见下） | 阻止下划线斜体 |
| `\` | `\\` | 让反斜杠按字面显示，不再吞掉后一个字符 |
| `==` | `\==` | 阻止高亮 |
| `===` | `==` | 第三个 `=` 会撤掉反斜杠，你真正想高亮时仍然可用 |
| 行首 `*` 后再敲空格 | `* ` | 反斜杠被撤掉，列表圆点仍是列表圆点 |
| `#include`、`#define`、`#ifdef` 等 | `\#include` 等 | 阻止指令被收进标签库 |

有两条例外值得单独说明：

- **变量名里的下划线保持干净。** 只有前一个字符不是字母或数字时 `_` 才被转义，所以 `my_var_name` 原样写入，而 `_private`、`_text_` 会被转义。这样源码里的变量名依然好读。
- **连着按两个 `[` 时第二个放行**，双链 `[[` 照常能打。只有一段新方括号的第一个会被拦。

围栏代码块和行内代码内部，插件完全不介入。

### 粘贴

粘贴进来的文字按和打字相同的规则处理：先在剪贴板内容上跑一遍规则再插入。如果本来就没有需要转义的字符，粘贴直接交回 Obsidian，不干扰正常粘贴行为。往围栏代码块或行内代码里粘贴时不动手——代码本来就该待在那儿。可以用 **粘贴时同样转义** 关掉。

### 修复已有笔记

输入保护只覆盖新输入，改不了已经存进文件的字符。装好之后，先对旧笔记跑一次修复。打开命令面板（`Ctrl/Cmd + P`）搜索「修复」：

- **修复当前笔记：转义 Markdown 触发符号** —— 先试这一条。
- **修复当前文件（阅读模式也可用）** —— 结果一样，任何视图模式下都能用。
- **修复整个库：转义全部 Markdown 触发符号** —— 会弹确认框并提示将扫描多少文件。
- **转义选区中的 Markdown 触发符号** —— 只处理选中的文字。

修复是幂等的：已经转义过的 `\<` 不会再多一个反斜杠。围栏代码块与行内代码跳过。`a < b` 这类比较不会被碰，正常链接语法继续有效。撤销用 `Ctrl/Cmd + Z`；整库修复一次写很多文件，需要逐个文件撤销。

每次修复写盘前，原文件都会在同目录留一份 `<原名>.md.bak-<时间戳>`。扩展名不是 `md`，所以 Obsidian 不索引它，后续修复也不会扫到它。

### 从备份还原

两种方式：

- **命令**：*从最近备份还原当前文件* —— 找到当前笔记旁边最新的一份 `.bak-` 文件，用它覆盖笔记。
- **设置面板**：滚到 **备份与还原** 区块。第一个下拉选笔记，第二个下拉选版本（时间倒序，最新标「（最新）」），然后点还原。跨目录也能选，不必先把笔记打开。

还原是覆盖性操作，所以当前内容会**强制**先另存一份备份——不受「修复前自动备份」开关影响。万一选错版本，上一版还在。

## 哪些字符会被转义

| 输入 | 结果 | 原因 |
| --- | --- | --- |
| `vector<int>`、`less<T>`、`<div>` | 加 `\` | 长得像 HTML 标签 |
| `a < b`、`x <= y`、`<3` | 不动 | 不可能是标签开头 |
| `arr[5]`、`a[0]`、`T[N]`、`a[i][j]`、`m["k"]` | 加 `\` | 紧跟前导标识符的下标 |
| `[note]`、`[空白]` | 加 `\` | 裸方括号会被解析成链接标签 |
| `[文字](地址)`、`[文字][引用]`、`[[双链]]`、`[^脚注]` | 不动 | 真正的链接 / 脚注语法 |
| ``` / ~~~ 里的 `#include <iostream>` | 不动 | 代码必须保持原样 |
| `my_var_name` | 不动 | 词内下划线 |
| `_text_`、`_private` | 加 `\` | 词边界的下划线 |
| `a*b*c`、`int** p` | `a\*b\*c`、`int\*\* p` | 星号会触发强调 |
| `if (a == b)` | `if (a \== b)` | 两个等号会触发高亮 |
| `if (a === b)` | 不动 | 三个等号是高亮 |
| `# 标题`、`#tag`、`a # b` | 不动 | 不是指令的井号、真标题、真标签 |
| `a#b`、`https://x.com/p#if` | 不动 | 标签要求 `#` 前是行首或空白 |

## 工作原理

**拦截。** 监听器挂在 `document` 的**捕获阶段**，早于 CodeMirror 6（它的处理函数绑在编辑器元素上）。两个通道喂同一套规则：`keydown` 管打字，`paste` 管剪贴板——粘贴根本不产生 keydown，只挂键盘事件会整个漏掉。

```
按下 < [ * _ \ =  或  粘贴
   │
   ├─ 不在编辑器正文里？ ──────────────► 放行
   ├─ 在围栏代码块 / 行内代码里？ ──────► 放行（代码保持原样）
   ├─ 已经转义过？ ───────────────────► 写入裸字符
   ├─ `[` 紧跟另一个 `[`？ ────────────► 放行（双链仍可用）
   ├─ `_` 前一字符是字母或数字？ ───────► 放行（标识符内部）
   │
   └─ 拦截
        ├─ preventDefault()    阻止浏览器插入字符
        ├─ stopPropagation()   CodeMirror 收不到，自动配对不发生
        └─ editor.replaceSelection('\\<')   由插件写入转义形式
```

**修复。** 逐行扫描，用一个状态机跟踪围栏代码块的开关，不需要完整解析器。非代码行再按反引号切成普通段与代码段，只转义普通段。

`<` 在后面不是空白、数字或等号时才转义，于是 `a < b`、`x <= y`、`<3` 保持干净，而 `vector<int>`、`less<T>` 会被处理。

`#` 只在**前是行首或空白**、且后面紧跟 14 个已知指令词之一时才转义。这个条件与 Obsidian 自身的标签语法一致，所以 `[[笔记#标题]]`、`https://x.com/p#if` 这类锚点永远不会被误伤。

方括号采用两阶段策略，因为单个 `[` 无法判断自己属于哪一类。先在行内定位**保护段**——`[[...]]`、`[...](...)`、`[...][...]`、`[^...]`，再转义保护段之外的所有 `[`。紧跟标识符字符（`A-Z`、`a-z`、`0-9`、`_`、`]`、`)`）的方括号被视为 C++ 下标，永不保护，于是 `arr[5]`、`a[i][j]` 安全，而 `[文字][引用]` 仍被认作引用式链接。

围栏判定遵循 CommonMark：起始标记之后不能再含同种字符。这一条对 ```` ```文字``` ```` 出现在段落中间的写法很关键。

## 已知限制

- 拦截只作用于**编辑模式**（源码模式与实时预览）。阅读视图显示的是渲染结果，存量内容必须靠修复命令改源文件。
- 转义**会改写笔记源码**，每个字符多一个 `\`。渲染结果不变，但原始文本可读性下降。如果你把源码模式打开着，这些反斜杠会直接显示出来。想让片段保持干净，改用反引号包住。
- **「反斜杠按字面显示」开启后，手动输入的 `\<` 会失效**，因为输入的 `\` 被加倍成 `\\<`，渲染出来是字面 `\<`。
- 如果你确实要在笔记里写原生 HTML（如 `<div style="...">`），先用切换命令关掉防护。
- 如果你确实想让裸 `[...]` 被解析成链接标签，临时关掉方括号转义。
- 存量笔记里的触发符号**不会自动修正**，需要跑修复命令，或打开「打开笔记时自动修复」。
- 整库修复会一次写入多个文件，建议先拿单篇试。
- 整库修复扫描库内**全部** Markdown 文件，包括你放在库里的其他用途的 `.md`（备份目录、插件资源）。目前没有排除目录的功能。
- YAML frontmatter 也没有跳过。块状写法（`tags:` 换行加 `-`）安全，但行内写法 `tags: [C++, STL]` 里的方括号会被转义，导致该属性失效——frontmatter 里的标签请用块状写法。
- 拦截基于 DOM 事件而非 CodeMirror 扩展，所以不受 Obsidian 内部升级影响；但如果编辑器容器不再是 `.cm-content`，选择器需要跟着改。

## 版本历史

- **1.8.0** —— 预处理指令词表由 3 个扩到 14 个（`include`、`import`、`define`、`undef`、`pragma`、`line`、`error`、`warning`、`ifdef`、`ifndef`、`endif`、`elif`、`else`、`if`）。指令的命中位置从行首扩到「行首或空白之后」，句子中间提到的 `#include` 也不会再变成标签。合并了两处重复的正则。
- **1.7.0** —— 新增 **备份与还原** 区块：两个下拉框选笔记、选版本，不打开笔记也能还原。备份扫描改走磁盘适配器——`.bak-<时间戳>` 不被 Obsidian 索引，旧实现用 `vault.getFiles()` 永远找不到，等于该命令此前是失效的。备份名正则同时兼容旧版的紧凑格式 `-YYYYMMDDHHmmss` 与当前的 `-YYYYMMDD-HHmmss`。
- **1.6.0** —— 新增粘贴拦截与 *从最近备份还原当前文件* 命令。还原前必定先把当前内容存一份备份，选错也能退回。
- **1.5.0** —— 修复范围扩展到 `#`、`==`、`*`、`_`，并新增「修复前自动备份」。
- **1.4.0** —— 新增 Markdown 语法抑制：预处理指令不再变标签，`==` 不再高亮（只有 `===` 触发），斜体与下划线斜体禁用而列表圆点保留，反斜杠按字面显示。
- **1.3.0** —— 新增方括号保护：`arr[5]`、`a[i][j]`、裸 `[note]` 与尖括号同等待遇，同时保留 `[文字](地址)`、`[文字][引用]`、`[[双链]]`、`[^脚注]`。插件由 Angle Bracket Shield 改名为 C++ Input Protection（插件 id 变为 `cpp-input-protection`）。
- **1.2.2** —— 新增由 tag 触发的 release 工作流，为 `main.js` 与 `manifest.json` 发布构建溯源证明；README 改为英文优先，中文版移至 `README.zh-CN.md`。
- **1.2.1** —— 修正 manifest 描述的句尾标点以满足社区目录的提交要求，并同步 `versions.json`；无功能变化。
